# AI Talent Genome — веб-версия

Веб-интерфейс ИИ-помощника рекрутера: вход по телефону или через hh.ru, выбор вакансии, загрузка откликов и резюме, LLM-оценка кандидатов и страница с результатами анализа. Streamlit-MVP этого продукта — в репозитории [ai-talent-mvp](https://github.com/xtron11/ai-talent-mvp).

> Секреты (PostgreSQL, `JWT_SECRET`, `HH_CLIENT_ID`, `HH_CLIENT_SECRET`) задаются в `src/.env` — шаблон в [`src/.env.example`](src/.env.example).

## 🛠 Стек технологий
*   **Backend:** Python (FastAPI, Uvicorn)
*   **Frontend:** React / Vue (Vite + NPM)
*   **Database:** PostgreSQL
*   **AI Engine:** Ollama (локальные языковые модели)
*   **Auth:** Интеграция с HeadHunter (hh.ru) и SMS-авторизация

## 🚀 Инструкция по запуску

### 1. Подготовка базы данных
Перед запуском убедитесь, что у вас установлен и запущен **PostgreSQL**. Создайте базу данных для проекта. На данный момент реализована регистрация по номеру телефона и вход через аккаунт **hh.ru**.

### 2. Запуск Backend (FastAPI)
Перейдите в директорию исходного кода и запустите сервер:
```bash
cd src
python -m uvicorn main:app --port 8000
```

### 3. Запуск Frontend
Установите зависимости (если это первый запуск) и запустите сервер разработки:
```bash
npm install
npm run dev
```

### 4. Запуск ИИ-модели (Ollama)
Убедитесь, что Ollama установлена в системе. Запустите нужную вам модель (например, Llama 3):
```bash
ollama run llama3
```

## 🔄 Повторный запуск анализа
Если анализ уже был завершен, результат сохраняется в локальном хранилище браузера. Чтобы сбросить данные и запустить процесс заново, выполните следующие шаги:

1.  Нажмите **правой кнопкой мыши** в любом месте страницы и выберите **«Просмотреть код»** (Inspect).
2.  Перейдите на вкладку **Application** (Приложение).
3.  В левом меню раскройте раздел **Local Storage** и выберите `http://localhost:5173`.
4.  В появившемся списке найдите ключ `analysis_result` и **удалите его**.
5.  **Обновите страницу** (F5). Анализ начнется автоматически.

## 📝 Основной функционал
*   **Авторизация:** Вход через HeadHunter API.
*   **Регистрация:** Валидация и создание профиля по номеру телефона.
*   **Локальный ИИ:** Обработка данных без передачи на внешние облачные серверы.
*   **Кэширование:** Сохранение промежуточных результатов анализа в браузере для экономии ресурсов.
